# Heart Disease Prediction and Healthcare Data Analysis

## Project Overview
This project focuses on analyzing healthcare data and developing machine learning classification models to study heart disease-related patterns.

The project uses Python libraries for data cleaning, exploratory data analysis, visualization, preprocessing, model training, and evaluation.

## Project Objectives
- Analyze healthcare data.
- Perform data cleaning and preprocessing.
- Explore health-related attributes.
- Create meaningful data visualizations.
- Build machine learning classification models.
- Compare model performance.

## Dataset Information
- Dataset: Heart Disease Dataset
- Total Records: 297
- Total Columns: 14
- Target Column: target

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- ReportLab

## Machine Learning Algorithms
